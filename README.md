### 📌 Featured Projects

**[Hybrid RAG News Intelligence System](https://github.com/ad80702/newsrag-hybrid-search)**
Hybrid dense + sparse retrieval (FAISS + BM25) over live news data, with an evaluation framework achieving 92.3% retrieval accuracy and 84.6% answer accuracy.

**[Calibrated Readmission Risk Agent with Clinical RAG](https://github.com/ad80702/patient-risk-intelligence-agent)**
XGBoost readmission model on 98K+ patient encounters — diagnosed and corrected a 30-45pt probability miscalibration, added SHAP explainability and an agentic RAG layer for borderline-case lookups.

**[Multi-Agent Financial Filing Analyzer on AWS](https://github.com/ad80702/financial-intelligence-agent)**
4-agent pipeline (extract, validate, detect, synthesize) orchestrated via AWS Step Functions, pulling live SEC EDGAR filings and using Amazon Bedrock (Claude) for report synthesis.
